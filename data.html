How to Use This Page
  1. Select Locations: Choose one or more sampling sites. On a computer, hold Ctrl (or Cmd on Mac) and click to select multiple sites. On a phone, open Filters and tap the sites you want, or use your device's multiple-selection controls if Filters are not shown.
  2. Select Parameters: Use the parameter selection box to pick the water quality parameters (e.g., salinity, temperature) you want to view. You can only compare multiple parameters at once OR multiple sites, not both yet.
  3. Adjust Date Range: Move the start and end sliders to select sampling dates, then apply. Use All dates to reset the range.
  4. View Data: Click the Apply button, The interactive chart displays trends for your selections. The table below shows the raw data for further analysis.
  5. Download Data: Use the download button to export the filtered data as a CSV file.
